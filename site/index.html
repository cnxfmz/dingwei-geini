底图
GCJ-02 · 底图与坐标来自腾讯位置服务 · 人工修改仅保存在本机 · 括号内相对方位、企业全称、商户名与「X号门」等描述不参与地址解析，相关点已标记建议复核。
方法与数据口径

数据来源：页面不内置任何点位，第一次打开就是一张空白地图；点位全部来自你自己搜索、新增或导入。坐标与底图都来自腾讯位置服务（地图 JSAPI GL、关键词提示、地理编码、地点检索），坐标统一为 GCJ-02。若预览环境不提供 WebGL，页面自动使用腾讯静态底图（Web Mercator 投影，zoom=13 下已用图像配准标定：Δlng 0.01°=58.25px、Δlat 0.01°=68.73px）；若连地图服务也取不到（例如脱离 WorkBuddy 直接双击打开文件），则使用页面内嵌的 z15 离线底图快照（2646×1926，襄阳一带），保证任何环境都有底图，标记仍可拖动、点选、输入坐标校正。
落点规则：地址搜索和「新增」里的解析都会把地址拆成「门牌 / 主体名称 / 辅助地标」多条查询词交叉比对；门牌级（level ≥ 9）且可信度高（reliability ≥ 7）的结果直接采用，区级粗定位（level=4）、行政区不符、名称错配的结果一律弃用；只有 POI 近似匹配、出入口或楼内商户时标为「需复核」，并在卡片里给出备选位置。
误差控制：每次落点都会做一次逆地址解析，卡片显示命中名称、查询词、可信度与当前位置的标准地址；拖动标记、切换备选、手输坐标之后都会自动反查新位置。名称留空时按坐标反查到地点名自动填入，手填过就不再覆盖。
地址搜索：顶部搜索框调用腾讯位置服务「关键词提示」，先按原样查询；无结果时依次去方位词（向东100米、对面等）→ 去企业后缀（有限公司、集团等）→ 去行政区前缀 → 取主体名重试，最多 4 次且串行留间隔以免接口限流；仍无候选时走「门牌精确解析」（地理编码）。命中后飞行到 zoom 17（约 1.2 米/像素，可辨楼栋），页面给出标准地址、GCJ-02 坐标与精度级别。搜到的点默认只作临时查看，点「加入清单」才进入右侧清单并参与 CSV / 图片导出；点位存在 localStorage（键 xy_points_v1），搜索历史另存本机（键 xy_search_hist_v1，最多 6 条）。快捷键 ⌘/Ctrl + K 聚焦搜索，↑↓ 选择，Enter 定位（无选中时按门牌解析），Esc 关闭。
地址服务 Key：在线打开时，地址查询要有一把腾讯位置服务 WebService Key（0 元申请，个人版每日 1 万次）。页面已内置一把可直接用；想换自己的，到「设置 → 地址搜索服务」粘贴、点「测试」确认连通、再「保存」，自填的只存本机（键 xy_tx_key_v1），清除后回到内置那把。没填时搜索、门牌解析、按坐标取名都会给出提示并带「填入 Key」入口，底图与拖动校正不受影响。
语音输入：搜索框右侧话筒按钮，点一下开始（图标变红并脉动），说地名，停顿后自动填入并搜索；再点一次或按 Esc 取消（输入框恢复原样）。用的是浏览器自带的识别能力，Chrome 的识别服务在境外，国内网络或微信内置浏览器里可能连不上 —— 此时会直接提示改用输入法键盘上的话筒，不会静默失败。
清单维护：左侧「＋新增」可只填名称（先挂起为「未匹配」），也可填地址（关键词提示 / 门牌解析取坐标，多个候选时点选一处）或直接填 GCJ-02 经纬度；新点编号取当前最大号 +1，全部点位一起参与 CSV / JSON / 图片导出。停用只把标记置灰并移出统计，点仍在图上、仍参与导出（状态列写「已停用」）；删除是彻底移除、不可恢复。「一键清空」会删掉本机全部点位与搜索历史，回到空白地图。 保存与导出：所有点位（含停用与人工校正）自动保存在浏览器 localStorage（键 xy_points_v1），仅存本机；换设备前用「保存」存成 JSON，到新设备「导入」即原样还原。导出 CSV / JSON 含原始地址、命中名称、标准地址、经纬度、坐标系、状态、来源与备注。点击「导出图片」可生成 PNG：当前视图（所见即所得）、点位图集（总览 + 每个落点一张 zoom 18 楼栋级特写拼版）、单点特写（1500×1100，0.5 米/像素）。图片由腾讯静态图接口按 Web Mercator 取图后拼接，拼接处已裁掉重复水印并在页脚统一署名；坐标与状态取页面当前值，含人工校正。 示例：「更多 → 载入示例」会加入 1 个示例点位（昭明台），只用来快速看效果，它们和普通点位一样可以拖动、停用、删除。
